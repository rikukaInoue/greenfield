# MetricUnreadable — gauge が観測不能(-1)

**意味**: SQL 由来の gauge(outbox_pending / contract_pending 等)が DB を読めていない。
0(問題なし)と欠測を混同しないための規約値 -1 が実際に出ている状態で、**このアラート自体が
「監視の監視」**(観測が死んでいるのに全アラートが静かなまま、を防ぐ)。

**切り分け**
1. アプリ本体も 5xx を返している → DB 障害。こちらが本題
2. アプリは正常でメトリクスだけ -1 → gauge のクエリが参照するテーブルが無い
   (マイグレーション漏れ)か、メトリクス用の接続だけ壊れている

**対処**: 1 は DB の Runbook へ。2 は migrate status で適用状態を確認。

**根拠**: telemetry の -1 規約(#59)。
