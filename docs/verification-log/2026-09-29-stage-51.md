## 2026-09-29 — [5.1] Tier 2（Caddy）: コンテナ化しても issuer 整合が保たれる（#55）

環境: OrbStack、compose（keycloak / openfga / authz / photo / caddy）。
photo は本番アダプタ（OIDCDeps: oidcauthn + authzhttp）で起動。

## 罠の再現（before）

コンテナ化した photo に「コンテナから届く名前」の issuer を与える:
`OIDC_ISSUER=http://keycloak:8080/realms/greenfield`。
ブラウザ経路（`127.0.0.1:8180`）で取った alice のトークンは
`iss = http://127.0.0.1:8180/realms/greenfield`。

```
GET /v2/photos (Bearer <ブラウザ経路のトークン>)
→ 401  Www-Authenticate: Bearer error="invalid_token"
```

**ブラウザが見る issuer 名とコンテナが解決できる issuer 名が食い違うと、
署名が正しくても iss 検査で落ちる**（internal-07 の罠そのもの）。

## Tier 2 で解消（after）

`deploy/compose/tier2.yaml`（override）: Caddy を compose ネットワークに置き、
`auth.localhost` / `photo.api.localhost` / `gear.api.localhost` を **network alias** として
Caddy に張る。photo / authz は `OIDC_ISSUER=http://auth.localhost/realms/greenfield`。

| 測定 | 結果 |
|---|---|
| `auth.localhost` 経由で取ったトークンの iss | `http://auth.localhost/realms/greenfield`（Keycloak start-dev は Host ヘッダから issuer を組む） |
| 同トークンで `photo.api.localhost/v2/photos` | **200**（oidcauthn → authzhttp → authz → OpenFGA の全経路） |
| photo / authz の起動時 discovery + JWKS 取得（alias 経由） | 成功（authz ログ `authn enabled issuer=http://auth.localhost/...`、photo は OIDC モードで healthy） |
| 罠のトークン（`127.0.0.1:8180` 発行）| 引き続き **401**（安全側は保たれる） |

→ check「アプリをコンテナ化しても issuer 整合が保たれる」**成立**。

## 副産物の罠: curl は *.localhost の DNS を引かない

コンテナ内から `curl http://auth.localhost/...` で疎通確認しようとすると、
**curl 8.x が RFC 6761 を自前実装しており、`*.localhost` を DNS を無視して
ループバックへ解決する**（`curl -v` で `Trying [::1]:80` を確認。getent は
alias どおり Caddy の IP を返すのに、curl だけ無視する）。

このため alias の検証を curl でやると自分自身へ繋がり、別サービスの 401 が
返って混乱する（実際に photo の 401 が返り、アクセスログの trace_id 照合で
正体を特定した）。**コンテナ内からの疎通確認は `curl -H "Host: auth.localhost"
http://<CaddyのIP>/...` の形で行う**（この形なら 200 を確認済み）。
Go の net はこの特殊扱いをしないため、アプリ本体の動作には影響しない。

なお OrbStack ではコンテナ内の未 bind のループバック :80 への接続が
自コンテナの公開ポートへ届く挙動も観測した（`::1:80` → photo の :8080 相当。
機構は未特定）。curl の件と合わさると誤診しやすいので記録しておく。

## 使い方

```
mise run tier2:up    # Caddy + authz + 本番アダプタ photo
mise run tier2:down  # Tier 1 の photo に戻す
```
