## 適応度関数（`mise run lint:secure-defaults`、check に常設）

`dev/scripts/secure-defaults-check.sh` が3つを機械で守る: (1) 全 Dockerfile の最終
ステージに USER がある、(2) 全 aws_db_instance / aws_rds_cluster に
storage_encrypted = true、(3) tf の environment に db_password / devtoken の参照が無い。
**3ルールとも変異（USER 削除・暗号化削除・平文復活）で検査が落ちることを確認済み**。
走査 0 件は失敗（fail closed）。

## 注記（還流時に効く制約）

- SSM パラメータの値は **tf state には残る**（このスタックは state がローカル + gitignore
  なので許容）。本番還流時は state の置き場（暗号化された remote state）とセットで考える
- 自己署名の ACM インポートは「TLS の配線」の検証であって、信頼チェーンの検証はしていない。
  ドメイン + ACM 発行に差し替えても配線（443 リスナー・リダイレクト・SG）は同一
- ECS の run-task は containerOverrides で entryPoint を変えられない。コンテナ内の
  uid 確認はイメージ単体（`docker run --entrypoint id`）で行った
